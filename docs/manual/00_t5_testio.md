# e_testio: Qu-Bit's input test

Qu-Bit's built-in test: the inputs go straight to the outputs, unchanged. Use it to check cables, levels and the
input gain.

**Bank:** factory.

## Controls
| Control | Does |
|---|---|
| **Source** (button or gate) | Mute the inputs |
| alt **Speed** | The Nebulae's input gain |
| Everything else | Not used |

## Quick start
1. Patch a sound into **in L** / **in R** and load it: it comes out of **out L** / **out R**.
2. Hold Source and turn Speed to set the input gain.
